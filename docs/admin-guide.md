# 网站后台使用教程

本文档面向站点管理员、运营人员和内容发布人员，说明如何在这个项目中完成日常后台操作。它偏“使用手册”，而不是源码说明。

## 1. 登录后台

1. 打开站点首页
2. 访问 `/admin/`
3. 使用管理员账号登录
4. 若没有账号，需先由系统管理员在服务器侧执行：

```bash
uv run python manage.py createsuperuser
```

然后回到后台登录即可。

## 2. 后台职责分工

这个项目不是纯“一个管理员做全部事”，而是分为几类典型岗位：

- 超级管理员：拥有站点最大权限，可看所有数据和配置
- 内容管理员：负责新闻、教程、关于页等内容发布
- 任务管理员：负责任务、标签、协作事项管理
- 审核管理员：处理身份验证、教程审核、活动审计等
- 运营/站务：看消息、反馈、站点策略、邮件/审核状态

实际权限由 Django 的 `has_perm` / `permission_classes` 管理，不要依赖“看组名”判断是否能操作。

## 3. 账号与用户管理

### 3.1 创建普通用户

在 Django Admin 中：

1. 进入 `Authentication and Authorization -> Users`
2. 点击 `Add user`
3. 填写用户名、密码、邮箱（如有）
4. 保存
5. 如需要，设置用户所属权限、状态和验证信息

### 3.2 审核用户身份

如果站点开启了身份验证链路：

- 账号进入待验证状态
- 管理员在审核列表中查看材料
- 通过、拒绝或停用账号

这部分通常在 `accounts` 相关视图和 `IdentityReview` 模块中实现。

### 3.3 用户资料

管理员可关注：

- 是否已绑定邮箱
- 是否已验证身份
- 是否有头像、昵称、个人简介
- 是否存在异常登录会话

## 4. 新闻发布

新闻模块通常由后台负责人日常维护：

1. 登录后台或通过前端入口进入新闻管理页面
2. 确认文章标题、摘要、正文和发布时间
3. 检查图片或附件是否正确上传
4. 点击发布/更新
5. 在前端检查该新闻是否展示正确

建议：

- 发布前检查是否有敏感内容
- 图片尺寸尽量控制在常见范围
- 若需要定时发布，必须确认时间设置正确

## 5. 任务管理

任务模块一类典型的协作工具：

- 创建任务
- 指派负责人
- 添加协作者
- 设置优先级/状态
- 关联标签
- 处理验收与关闭

常见操作：

1. 新建任务
2. 填写描述、开始/截止时间
3. 选择负责人
4. 绑定 tag
5. 维护状态流转

建议：

- 每项任务有明确责任人
- 状态变更要及时更新
- 超期任务要同步提醒

## 6. 活动管理

这个项目中的活动链路比较完整，通常需要运营和审核协同：

- 制定活动类型：众议 / 征集 / 展示
- 设置活动时间和状态
- 管理活动投稿或投票
- 审核作品/展示内容
- 处理结项和结果公开

如果你做活动运营，重点关注：

- 活动时间与状态是否一致
- 是否有投票/投稿关闭时间错误
- 是否有未处理的作品或审核项
- 结项后是否已对外展示正确

## 7. 反馈与提案处理

反馈模块通常用于：

- 建议
- 投诉
- 举报
- 运营问题

管理员应该：

- 按匿名/署名形式区分处理
- 重点查看有证据或附件的反馈
- 对敏感反馈保留证据链
- 形成线下跟进机制，不完全依赖系统内对话

## 8. 教程管理

教程支持上传视频/文档并按标签归类，适合知识库建设。

日常操作：

1. 进入教程入口
2. 新增教程
3. 上传封面/资源文件
4. 填写标签、简介和审核信息
5. 提交审核
6. 审核员进行通过/驳回

管理员要确认：

- 文件可正常播放/下载
- 标签分类合理
- 审核状态准确
- 已过期或不合规内容及时下线

## 9. 关于页与站点政策

站点说明页和政策页属于“站点公共文案”管理：

- 关于社团
- 关于校园
- 关于网站
- 联系方式
- 校园一览等

维护时要注意：

- 内容应与当前实际情况一致
- 站点政策要及时更新
- 公开信息不要出现过时、错误或已失效的链接

## 10. 文件与附件管理

附件模块是整个系统的底层媒体管理：

- 用户上传图片/视频
- 活动作品附件
- 教程文件
- 反馈证据

存储时要注意：

- 定期清理无效附件
- 不要让重复文件造成存储膨胀
- 确认权限，避免私密附件被公开访问

## 11. 日常运营建议

- 每天至少检查一次：站点状态、账号状态、待审核事项、异常任务
- 每周至少做一次：内容校对、附件清理、后台账号盘点
- 所有重要内容变更最好在发布前做一次预览
- 辅导/运营团队不要在生产站直接做未测试改动

## 12. 常见问题

### 12.1 无法登录

可能原因：

- 账号未创建
- 账号密码错误
- 用户未通过验证
- 角色权限不够

### 12.2 页面内容不展示

可能原因：

- 数据未保存
- 前端缓存未刷新
- 静态资源构建未更新
- 后端返回了错误状态

### 12.3 反馈或附件无法看见

- 检查是否已经保存并关联到目标对象
- 检查附件存储路径是否正确
- 查看后台日志和数据库状态

## 13. 操作建议总结

如果你是第一次管理这个站点，最值得熟悉的工作流是：

1. 用户与权限
2. 新闻内容
3. 任务协作
4. 活动与审核
5. 教程和附件
6. 常用日志与状态检查

这六步几乎覆盖了日常运营的主体工作。
