# 后台委任是一条验证通道（不是逃生舱）

日期：2026-08-27 · 与 jinha 协作

管理员 / 超级管理员已在后台委任，身份不必再走邮箱或人工审批。面板需要能**显示**这一点。

**账号「已验证」仍是任一通道 approved。** 委任落成一条只读通道（`appointment` / 后台委任）：`is_staff` 或 `is_superuser` 时自动 approved，撤销则删行。`is_verified` 与 `IsVerified` 都不读这两个标志位——超管也不走验证轴特判，身份由通道确立。

权限轴逃生舱不变：超管 `has_perm` 恒真（ADR-0005 决策 9）；秘密票明细仍仅 `is_superuser`（ADR-0007）。那是能力 / 敏感读，不是验证。

## 被否方案

- **把 `is_staff` / `is_superuser` 扩进 `IsVerified` 逃生舱**：验证轴再开绕过，面板仍可能显示「未验证」。否（走通道）。
- **只改文案、不建通道**：徽章是管理员，验证面板却仍是访客通道。否。
